# Cartes de voyage

Cartes de randonnée et de visite, pensées pour le téléphone : plan OpenStreetMap, étapes numérotées avec photo, noms en chinois à montrer, conseils de timing, et position GPS en direct.

| Carte | Lien |
|---|---|
| Sommaire | https://yusuf-oph.github.io/cartes-voyage/ |
| Xidi (西递) | https://yusuf-oph.github.io/cartes-voyage/xidi.html |
| Hongcun (宏村), de l'aube au départ | https://yusuf-oph.github.io/cartes-voyage/hongcun.html |
| Sommet du Huangshan (黄山), deux jours | https://yusuf-oph.github.io/cartes-voyage/sommet.html |

## Utilisation

1. Ouvrir le lien dans Chrome ou Safari.
2. Toucher 📍 en haut à droite de la carte, puis autoriser la localisation : le point bleu indique votre position.
3. Toucher un numéro sur la carte pour afficher l'étape (photo, caractères chinois, pourquoi y aller, quoi sauter si l'on est pressé).

Une page déjà ouverte reste lisible sans réseau ; la position GPS fonctionne en général aussi hors connexion une fois la page chargée, avec une précision parfois moindre.
